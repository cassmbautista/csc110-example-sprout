# CSC110 Concepts (for the concept map)

Covered in class, so students should recognize and explain these in their code:
- Values, variables, types (`int`, `double`, `boolean`, `String`, `char`), calculations, casting
- Input/output (`Scanner`, `System.out.println`), string concatenation and `String` methods
  (`length`, `equals`, `equalsIgnoreCase`, `contains`, `toLowerCase`, `trim`, `substring`)
- Conditionals: `if / else if / else`, boolean logic (`&&`, `||`, `!`), validation
- Loops: `for`, enhanced for-each, `while`, `do-while`, accumulators and counters, `break`
- Methods: parameters, return values, scope, breaking a problem into pieces
- Classes & objects: fields, constructors, `this`, getters/setters, `private` (encapsulation), `toString`,
  objects that hold references to other objects
- Arrays (1D and 2D) and `ArrayList` (`add`, `get`, `set`, `remove`, `size`, `contains`, `indexOf`),
  traversing, searching, filtering into a new list
- Testing with JUnit (reading tests, assertions)

Not covered (mark `// BEYOND CSC110:` in code): Swing/GUI, event listeners and lambdas, file I/O, exceptions
and `try/catch`, `static final` constants beyond the basics, inheritance/interfaces, enums, `Collections` utilities.
