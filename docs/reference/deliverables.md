## How to turn things in
Everything lives in your **public GitHub repo**. On Canvas you submit only your repo link (once it's set up in class) and
your slide deck (Dec 9). `/checkpoint` **tags** each deliverable so I can see what you had on the due date:

| Tag | What's in it |
|---|---|
| `proposal` | `docs/01-proposal.md` |
| `plan-design-prototype` | `docs/02-project-plan.md`, `docs/03-class-design.md`, `docs/04-ui-prototype.md` + screenshots, `docs/prototype/index.html` |
| `final` | Working program, `README.md`, `docs/final-writeup.md`, `docs/concept-map.md`, `docs/steering-log.md`, sample data in `data/`, slides PDF in `docs/` |

**I grade your program by downloading your repo** and running `run.bat` / `bash run.sh`. If it doesn't compile from a
fresh download, it can't earn "working" points. Try it in a new folder before Dec 9.
JUnit tests are **not graded**. The skills write a few because they help Claude write correct code. Keep them.
